# Ethics and Limitations

This system is not a universal lie detector. It estimates deception-risk patterns only under controlled experimental conditions.

## Key Limitations

- Current results are prototype-level because the dataset is small.
- Eye-tracking data is sensitive and should be handled carefully.
- False positives can harm truthful participants by incorrectly flagging them as deceptive.
- No real names or direct identifiers should be stored.
- Model performance may not generalize across devices, lighting conditions, populations, or tasks.
- Thresholds are preliminary and must not be treated as final deployment rules.

## Deployment Requirements Before Real Use

Real deployment would require ethics approval, informed consent, larger subject-independent datasets, calibration validation, cross-device testing, countermeasure-aware evaluation, and human oversight.

Outputs should be interpreted as risk indicators, not final truth/lie judgments.
